# Miss Kudi Productions — Website Starter

A responsive Next.js website starter for a Lagos-based B2B garment manufacturer and private-label production partner.

## Included
- Responsive homepage with brand positioning, service overview, production process, and inquiry form
- Initial SEO metadata
- Inquiry endpoint with required-field validation
- Provisional editorial visual system

## Important before launch
- Replace all stock photography with Miss Kudi Productions' approved logo and authentic production photos.
- Set the real production contact details and canonical domain in `src/app/layout.tsx`.
- Connect the inquiry endpoint to approved business email and/or a database. The current endpoint intentionally returns preview mode and does **not** store or send inquiries.
- Add spam protection, privacy notice, retention policy, and secure file upload workflow before accepting confidential design files.
- Confirm exact service scope, minimum quantities by garment, delivery/export capabilities, and any quality standards before publishing claims.
- Run `npm install`, `npm run dev`, and `npm run build` locally before deployment.

## Deploy
Push this project to a GitHub repository and import it into Vercel. A custom domain can be attached after selecting and registering one.
